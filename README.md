# Mat Nham Mat Mo by HieuThuHai

A dedicated website to showcase HieuThuHai's latest work and popular songs. His growing impact has been recognized with multiple accolades, including “Most Favorite Male Artist” at the 2023 Làn Sóng Xanh Awards; both “Male Artist of the Year” and “Most Favorite Male Artist” at the 2024 Làn Sóng Xanh Awards; and the title of #1 in Vietnam’s Top Local Artists 2024 by Spotify.

The website is made with simple web design techniques and principal. Using HTML/CSS and JavaScript as the main languages.
